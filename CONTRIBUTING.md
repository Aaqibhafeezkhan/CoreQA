# Contributing

1. Use PHP 8.2 or newer with the PDO driver required by your database.
2. Copy \`.env.example\` to \`.env\` and run the application from the repository root.
3. Run \`php bin/lint.php\` and \`php tests/run.php\`.
4. Keep changes focused and add regression tests for changed behavior.
5. Use Conventional Commit subjects.
6. Sign every commit with \`git commit -s\` and the DCO sign-off trailer.

Do not commit credentials, \`.env\` files, or runtime database files.
